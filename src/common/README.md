# common

Каталог `common` содержит общий код проекта.

## Файлы

```text
config.c / config.h      чтение конфигурации сервера
users.c / users.h        чтение whitelist пользователей
protocol.c / protocol.h  сборка и разбор запросов
log.c / log.h            логирование
```

## Протокол

Используется простой текстовый протокол.

Запрос:

```text
login:command
```

Ответ:

```text
code:result
```

Коды ответа:

```text
0 — команда выполнена успешно
1 — ошибка
```
